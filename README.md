## 📌 Sobre o projeto

O **Gráfica Macedo's** é uma aplicação web desenvolvida com Next.js que reúne a apresentação digital da gráfica e ferramentas para facilitar a criação de materiais personalizados.

O projeto foi desenvolvido para oferecer uma experiência simples e prática, permitindo que os usuários conheçam a gráfica e utilizem recursos de edição diretamente pelo navegador.

## ✨ Funcionalidades

### 🏠 Site institucional

- Apresentação da Gráfica Macedo's.
- Identidade visual baseada nas cores da marca.
- Acesso rápido ao atendimento pelo WhatsApp.
- Link para o Instagram da gráfica.
- Interface adaptada para diferentes dispositivos.

### 🖼️ Editor de fotos

Ferramenta para preparar imagens para impressão e personalização.

- Recorte de imagens em formato circular, quadrado ou retangular.
- Ajuste de zoom para posicionar a imagem.
- Visualização da imagem durante a edição.
- Download do resultado final.

### 🏷️ Gerador de tags personalizadas

Criação de folhas de tags circulares prontas para impressão.

- Geração de folhas no formato A4.
- Organização de tags para impressão.
- Exportação do resultado em PDF.
- Geração de arquivos utilizando a biblioteca jsPDF.

## 🚀 Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.

### 1. Clone o repositório

```bash
git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
```

> Substitua a URL acima pelo endereço real do seu repositório GitHub.

### 2. Acesse a pasta do projeto

```bash
cd SEU_REPOSITORIO
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Inicie o servidor de desenvolvimento

```bash
npm run dev
```

Acesse a aplicação em:

http://localhost:3000

## 📦 Build de produção

Para gerar a versão otimizada da aplicação:

```bash
npm run build
```

Para executar a aplicação compilada localmente:

```bash
npm start
```

Unir desenvolvimento web e necessidades reais de uma gráfica, criando ferramentas digitais que simplificam a personalização de imagens e a preparação de materiais para impressão.

O projeto também serve como aplicação prática de desenvolvimento com Next.js, React e JavaScript.
